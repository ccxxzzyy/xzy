SVG 图标演示

Lucide 通过 JavaScript 将 <i> 标签替换为内联 SVG，图标本质是矢量图形，可用 CSS 精确控制颜色与大小

data-lucide="heart"

data-lucide="star"

data-lucide="zap"

尺寸缩放

SVG 矢量图形任意缩放不丢失清晰度，宽高通过 width/height 属性控制

常用图标

页面加载时 lucide.createIcons() 自动将 data-lucide 元素替换为内联 SVG

交互演示

点击大图标切换描边颜色，或点击下方按钮

使用方式

引入本地 lucide.min.js，用 data-lucide 属性声明图标，createIcons() 自动转换为 SVG

<!-- 引入脚本 -->
<script src="cdn/lucide/lucide.min.js"></script>

<!-- 声明图标（属性值为图标名） -->
<i data-lucide="heart"></i>
<i data-lucide="star"></i>

<!-- 页面加载完成后自动替换为内联 SVG -->
<script>lucide.createIcons();</script>
