JavaScript 6 种基础数据类型

点击下方按钮查看每一种类型的运行结果

1. String 字符串

由引号包裹的文本，可以用单引号、双引号或反引号定义

let xzy_str1 = "Hello"; let xzy_str2 = 'World'; let xzy_str3 = `模板字符串 ${xzy_str1}`;

2. Number 数字

包括整数和浮点数，还有特殊值 NaN 和 Infinity

let xzy_num1 = 42; let xzy_num2 = 3.14; let xzy_num3 = NaN; let xzy_num4 = Infinity;

3. Boolean 布尔

只有两个值：true（真）和 false（假）

let xzy_bool1 = true; let xzy_bool2 = false;

4. Null 空值

表示"什么都没有"，一个故意留空的值（typeof null 返回 "object" 是历史遗留 bug）

let xzy_nullVal = null;

5. Undefined 未定义

变量声明了但没有赋值，或者访问不存在的属性

let xzy_undefVal; let xzy_obj = {};

6. Symbol 符号

ES6 新增，每个 Symbol 都是唯一的，常用于对象属性名避免冲突

let xzy_sym1 = Symbol("id"); let xzy_sym2 = Symbol("id"); let xzy_symObj = { [xzy_sym1]: "唯一值" };
