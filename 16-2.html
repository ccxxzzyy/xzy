📦 对象 Object
  • 无序的键值对集合：{ key: value }
  • 访问：obj.key 或 obj['key']
  • 可增删属性：赋值即新增，delete 删除
  • 遍历用 for...in / Object.keys()
🎞️ 字符串 String
  • 有序的字符序列，下标从 0 开始
  • 长度是属性：str.length（不是方法）
  • 所有方法都不改原字符串，返回新值
  • 模板字符串：`你好, ${name}`
